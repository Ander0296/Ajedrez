# PROGRESO — una fila por semana

La escribe `/semana`. Rápidas = rating al cierre de la semana. Problemas = el
que se ve en el perfil (la API no lo da). s/jug, < 3 s, derrotas cortas y
rendiciones = `uv run ajedrez resumen --dias 7`. Analizadas = con `/partida`.
